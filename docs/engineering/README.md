版本：**工程契约 2.0.0，2026-10-18**。状态：可供开发启动的设计基线，尚无产品实现或运行验收。本文档集面向 macOS 开发验证版和“1 总控＋4 开发”协作。

本轮只产出文档与静态检查，不创建 App、测试程序、依赖或运行配置，不启动服务、不处理或上传录音、不调用模型 API、不读取本机凭据或保存/验证密钥值，不初始化 Git 或创建开发对话。

## 要求、设计、假设的区别

| 标记 | 含义 | 可由谁改变 |
| --- | --- | --- |
| P：已确认要求 | 三层内容、录音可靠性、五档同事实、引用与删除、多窗、时效等 | 用户；开发对话不得降级 |
| E：工程设计 | 本文推荐的进程边界、字段、状态机、事务和目录所有权 | 总控按下述契约变更流程；不得违反 P |
| U：待验证假设 | 某库能否满足输入法/恢复/重构/时延，参数是否合适 | 责任开发对话提供实验，总控复核；质量门槛未定者与用户共同锁定 |

除明确引述产品要求或官方事实，本文所有实现选择均为 E，而非“用户已经确认此数据库/库/算法”。U 项统一编号见 [VALIDATION](VALIDATION.md)，不得把官方支持、样例通过或本地 commit 记成真实课程验收。


## 本次新增能力入口

- **P：原生交互知识可视化**。自动发现值得探索的知识点，插入真正可交互的2D/3D笔记对象。E首选受控注册表＋结构化参数、宿主确定性计算、前端受控渲染；不默认保存模型代码。见ARCHITECTURE §8、DATA §11、WORKSPACE §10；验收V18–V21、实验U11/U12。
- **P：全文搜索与Command+F**。课件、笔记、原始/二次转写都覆盖。E默认当前聚焦内容窗、当前可见档/版本；宿主本地索引查询，按稳定锚点跳转。见ARCHITECTURE §9、DATA §12、WORKSPACE §11；验收V22–V24、实验U13。
- **P：focaus**。原“快速跟上”正式更名为小写focaus；自适应总结与恢复理解的连续上下文是目标。E用有来源的理解路径组织漏听重点、讲授衔接、当前问题/步骤和必要前置，可合并表达。它不等同笔记整理或进度定位；完整输出≤15秒，正文固定，指针持续更新。见ARCHITECTURE §10、DATA §13、WORKSPACE §6；V25/V26扩充V06/V07，U14扩充U05。

三项均未实现。候选库、数学实现、索引性能和理解效果必须经相应U/V验证；Command+F范围、注册表协议、索引算法及结果字段是工程推荐，不是用户逐字段确认。

## 版本与跨模块变更

分别管理 `contract_version`（IPC/任务）、`format_version`（资料包）、`schema_version`（数据库整数迁移）和每实体 `revision_id`。它们不能互相代替。本次从文档1.0.0升级工程契约至 `2.0.0`，资料格式至 `focaus.material/2.0.0`；数据库仍没有实施，第一版由总控G1建立。交互组件子协议另用 `focaus.visualization/1.0.0`，不等于资料格式版本。

| 变化 | 升级原因与兼容政策 |
| --- | --- |
| C07/C08、capability协商、C09必填语义 | IPC新增命令/任务/事件，focaus结果要求路径、前置及双时间依据；旧消费者无法保证正确解释，升major |
| C05新增 `interactive_visualization` 判别分支及必填 `search_units/search_coverage` | 旧资料读取方不能静默忽略对象或把未索引当无结果，资料格式升major；所有普通对象也需声明搜索覆盖 |
| 旧1.x资料/备份 | 原包不可变；显式导入适配器保ID/原版本，建立新解析revision，提取已知文字、未知区标未处理，不编造交互或OCR。旧引用仍指原版本 |
| 旧CatchupResult | 保留内部名与 `catchup.request`/kind `catchup`；适配为 `legacy_summary` 历史展示，不补造讲授路径或将其计入新验收；新触发才按C09生成 |
| 旧/未知读取方 | 握手核对major和具体组件能力；未知major拒写/拒导入，已知包内不支持模板仅显示明确静态降级/unsupported，原数据可无损保留，不能标交互完成 |

没有已实现数据库或部署客户端需要本轮运行迁移；上述为G1必须实现的兼容契约，不是迁移已完成。schema_version由实际迁移决定，不能机械赋为2。C01–C06、V01–V17、U01–U10编号保留，新内容只追加。

总控拥有公共类型、格式 Schema、数据库迁移、接口版本、本套工程文档及权威 continuity。四路开发只提交变更建议：现契约版本、问题证据、最小字段/语义 diff、生产者/消费者清单、兼容与迁移、样例、验证影响。总控核对产品边界后出单一变更提交，发布新契约版本与共同基线 commit，各路确认消费版本再继续相关写入。不允许先私改公共类型再要求其他路适配。

语义破坏或必填变化升 major；兼容可选字段升 minor；不改变序列化/语义的纠错升 patch。未支持的 major 拒绝写入。任务冻结发起时版本，长任务跨升级返回须通过适配器校验，不能直接入库。对同一输入重复生成的缓存也带契约、模型配置、提示模板版本。

用户改变产品范围时由总控同步 continuity；工程细节由总控记录为工程决定。原有产品/路线/生命周期原文维持只读，过时差异写入 continuity 并链接，不双向自动同步。

## 当前可用性与开发门

本工作区在 2026-10-18 再次核实非 Git 仓库。文档可用于拆分任务，但四路真正并行须由后续总控完成 G0/G1：取得开发与仓库操作授权、排除参考和大文件、建立可提交基线、落地 C01–C09 的机器契约与样例，然后建立独立 worktree。仅看到这套文档不等于获得上传音频、调用付费模型或发布的授权。
