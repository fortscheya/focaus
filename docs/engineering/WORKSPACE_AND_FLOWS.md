# 工作区与关键流程

工程契约 2.0.0｜2026-10-18。普通UI使用HeroUI React v3默认设计；本文件定义行为与事务，不规定像素、品牌配色或动画曲线。所有持久变更由 [INTERFACES](INTERFACES.md) 中宿主命令完成。

## 1. 进入与录音

开始页突出开始录音，提供课程/课堂选择和新建。顶部设置与登录占位，底部线条箭头进入工作区，不用emoji。单纯进入工作区只导航；开始录音先提交 recording.start，立即启动原生采集，再上滑衔接常驻顶部状态，动画不在采集关键路径。

没有课程/课堂也能开始：宿主创建未归属会话，UI清楚显示“未分配”。新建/选择课程只是浏览；明确“分配/转移此录音”才改归属。麦克风权限未获准时显示starting/权限结果，不把启动按钮动画当录音成功；已有单一会话时给“查看当前录音、停止后开始本堂、整次转移”入口，不自动停止另一堂。

| 操作 | 用户可见状态 | 后台与失败边界 |
| --- | --- | --- |
| 开始 | 实际录音归属、时长、状态 | 先原声落盘；ASR离线/失败单独提示，不把未识别误写未录音 |
| 暂停 | paused，档位继续锁定，可回听 | 封存已采范围、保实际时间缺口；云任务可继续收尾 |
| 继续 | 先停应用内回放，再变recording | 采集恢复失败保paused并说明；不把回放音混入录音 |
| 停止 | stopping后stopped，回听与换档可用 | 封口确认后显示已保存；ASR/二次/笔记收尾显示各自进度 |
| 关窗口 | 对应视图消失，菜单栏仍显示录音 | 全应用最后一窗关闭仍保宿主/任务，不等于退出 |
| 明确退出 | 显示保存/任务checkpoint结果 | 停采并保存已采数据后退出；保存失败明确实际损失，不伪称完整 |
| 崩溃后启动 | 恢复已保存会话、缺口与未完任务 | 绝不自动开麦；用户重新采集，历史任务按checkpoint恢复 |

顶部常驻录音归属/状态/时长/暂停继续/停止/focaus，所有课程窗口显示相同全局录音事实；每窗的浏览课堂可不同。菜单栏提供相同控制。录音中禁止应用内原声播放，暂停/停止后允许。

## 2. 课程桌面与内容窗口

每课程有真正原生桌面窗口，切课程打开/聚焦该课程窗并直接进入工作区。左栏操作限定本课程；底部功能入口用当前所选课堂创建内容窗。每个内容窗标题/上下文明确 lesson_id 与内容类型，选择另一个课堂不重绑已开的笔记/课件/转写/AI窗，允许同课程跨课堂对照。

`ContentView` 与文档对象分离：多个查看视图可指同一版本化内容，但由 edit lease 避免同区域并发覆盖。拆出的是同一 view_id 的承载位置，非复制文档、录音会话或生成任务。

### 2.1 网格不变量

- 最多3列，每列最多上下2窗；每窗占一个格，禁止格内标签组。
- 非空时可见窗口自动平铺填满显示区，不留下空格；全无内容窗才为空。列宽、列内高度可调。
- 打开新内容优先使用可用格；六格满时显示“先关闭/移出一窗”或“独立桌面窗打开”。不自动关闭、隐藏或替换已有窗口。
- 左上悬停出现放大/缩小/关闭，键盘仍有可达等价操作。放大临时占满显示区，保存原布局用于恢复；这不是满六格时偷偷隐藏某窗腾位。
- 缩小/关闭释放显示位置，保view状态与后台任务；底栏可重开。平铺重排不能改变文档节点次序或选择课堂。

### 2.2 拆出、放回与恢复事务

1. UI记录当前文档已提交revision与未提交草稿、选区、光标、滚动、对象选择及IME状态。正在composition时先完成安全交接或暂缓，不截断汉字输入。
2. `view.move`向宿主预留目标格位/新原生窗，记录 transfer_id；原承载保持可恢复，暂冻结写入但不丢草稿。
3. 新承载读取同一view状态并调用view.ready，宿主原子移交edit lease，再释放原承载。新窗失败/崩溃则回滚，保原窗。
4. 放回若满六格返回GRID_FULL，原外窗保持正常，等用户腾位；绝不强行挤入标签格。
5. 关闭外窗只关闭视图，保状态；下次打开恢复同一内容上下文。移交或重开不会重新开始录音/再次提交生成任务。

窗口承载不承担业务真值；滚动/选区状态可独立版本化，不能用刷新整个编辑器DOM来呈现普通AI增量。

## 3. 浏览、归属与整次录音转移

普通选择课堂、打开课件、引用跳转均不改变录音归属。用户发现开始时分错课堂时，执行recording.transfer，UI在执行前明确范围：“整次录音、历史及后续采集、原始和二次转写归目标课堂；原课件和已有笔记保持原处”。真正跨堂则停止当前并新开，不从转移时刻自动切一半。

宿主执行一个归属事务：

1. 校验唯一会话及expected_epoch；无需停采，提升assignment_epoch。
2. 更新录音归属、两层转写的归属投影及相关目录索引，所有录音/句段/引用ID不变，音频字节不必搬家。
3. 旧/新课堂受影响笔记、安排、术语汇总标“来源或上下文可更新”，不自动搬笔记，不自动删用户内容。
4. 后续识别使用目标课堂热词/上下文。ASR连接不能安全更新时后台换连接，保尾部映射和去重；已经定稿的原始转写绝不重写。旧二次转写可提示重整。
5. 旧归属快照的进度/生成结果失效；用户仍可浏览原课堂笔记，来源导航能够跳到转移后相同录音实体，并说明其当前归属。
6. session录音档保持不变；目标课堂录音期间锁档，已存在笔记用actual/requested区分，不被转移操作强制改写。原课堂无活动会话则解锁。

中途崩溃后要么全部旧归属要么全部新归属，不允许一层转写留旧、一层搬新。正在输入的旧笔记保草稿和光标，受影响状态提示在内容外显示。

转移不搬原课程桌面窗。绑定旧课堂集合的转写窗移除该录音条目并提示已转移，不能继续把它计入旧课堂；通过引用打开、明确指向该recording/segment的来源视图仍保实体目标和阅读位置，显示其当前目标课堂。两种view target在契约中分别表达，不能因更新归属而把所有旧课堂窗口重绑。

## 4. 三层内容、订正与整理

原始转写窗区分provisional与final。中间识别可收敛；final保留原始底稿。二次转写是原话修剪，维持时间顺序和说话逻辑，学生问题保留，猜测不当教师确认，说话人不明就不硬标；跳页/续讲/说话人信息在正文外。明确自纠保前后两句，错说可淡化。

普通错字由AI判断后直接修正二次层，保审计无需额外视觉标记；关键含义变化只产生红下划线建议，显示建议与原因，不自动改原始句/二次原文。

### 4.1 订正浮层状态

| 用户动作 | 结果 |
| --- | --- |
| 点红线或文字 | 打开可编辑预填浮层，草稿状态，不立即采纳 |
| 修改建议后点击应用内浮层外 | 提交用户最终文本并采纳 |
| 未修改直接点应用内浮层外 | 仍采纳当前建议 |
| Esc | 取消此次浮层草稿；原建议仍pending，不等于拒绝 |
| 明确“保留原句” | suggestion变rejected，批量采纳跳过 |
| 切App/窗口失焦 | 保草稿，不自动采纳 |
| 输入法选词/组合 | 不作为outside click，不提交未完成输入 |
| Cmd+Z | 撤销最近采纳或整批事务；若已有后续编辑先检查冲突 |

一键采纳只处理当前二次层各处独立pending建议，预示适用数量，完成显示采纳/跳过数量，整批可撤销。明确拒绝项、来源版本变化的过期项跳过。后续整理沿用已采纳/拒绝记录，不能每轮重提相同已拒绝变化；新增实质证据可产生新建议并说明依据变化。

### 4.2 笔记与编辑稳定性

自动整理以作业/DDL/考点和完整知识段触发，每两分钟兜底检查，只整理新内容与确定部分。未完推导保留待完成状态，不整篇重写。停止后自动补尾，未补的ASR缺口明确展示。

手动全局重整展示结构/事实/来源差异再应用，保持fact/object身份；不是“替换整个文档JSON”。用户修改的文本、单元格、节点、连线逐项保护，正在输入的范围暂缓AI写入，其余范围可提交。用户删除意图持久化，重复整理不补回；新增实质信息只给恢复建议。

“上次总结于”是笔记/二次转写内容窗底部的UI元数据，由成功提交的generation时间得到，不进入正文/复制/Markdown/PDF正文。另列“依据截止于”及缺口，两者不可混用。重复任务无内容变化时不虚构一次新总结成功；仅改变UI查看时间不会更新generation时间。

## 5. 引用、旧版本与定义导航

点击来源先记录发起视图返回锚点（view_id、revision、光标、选区、滚动），解析SourceEdge并打开精确旧版本与区域。来源已升级但尚未采纳时仍打开旧位置，并可并排对照新旧增删，提示“可更新”；新资料待纳入另提示“有新来源”，二者不合并成一种模糊状态。

导航中间层缺失可沿已存链跳到下级，说明跳过二次/原始层及原因。数据层仍保存逐级边。来源永久删除只展示墓碑/不可用状态，不从缓存偷偷显示已删原文。返回原窗恢复阅读位置和编辑选区。

源窗需要新格但网格已满时，沿用腾位或独立窗入口；不能为完成引用跳转覆盖原编辑窗。短定义先浮层预览，明确点击再跳转；定义ID解析到目标笔记当前可见语言档，不以文字位置查找同名词。重定义按局部作用域和发生位置向后生效。

## 6. focaus：自适应总结、理解衔接与进度

focaus是用户可见的正式小写名称，入口位于顶部常驻区/快捷键和选段“从这里开始”。它帮助用户恢复继续听懂所需的上下文，不只给历史摘要或页码；详细展开交给笔记，全局进度仍由独立ProgressState维护。

1. 触发时记录triggered_at、单调计时起点和request_generation。默认回看max(估计漏听时长,5分钟)，可改范围或从已有转写/已总结内容指定起点。走神估计未定，不能把失焦/无操作当确定事实；估计不可得时标明采用5分钟默认。当前浏览课堂与录音归属不同必须显示focaus目标，不能暗改录音归属。
2. 快照立即读取当时可得转写、资料范围和全局进度，不等下一轮定位或历史补齐。界面显示生成中/证据范围。可中途取消；新触发为新代次，迟到旧结果不能覆盖新卡片。
3. 输出根据理解任务调整重点：长漏听给主题关系和接回关键链；推导中途补局部符号、条件、中间结论；讲例子说明应用的概念、选例的课堂依据和当前观察；主题切换说明前后关系。更早必要定义可引用既有课堂/同课程适用定义并标“窗口外前置”，不假定用户已经掌握或完全不懂。
4. 默认简短连贯，整合漏听重点、老师如何推进、当前问题/步骤和必要前置，不固定四块卡片或关键词清单。课堂证据支持的讲授关系与“系统补充解释”清晰区分；缺依据时直说不确定，不编造老师动机/因果链。定义仍按本课堂/局部作用域解析。
5. **从触发至完整结果可见≤15秒**，包含必要衔接与前提校验。部分输出/缺必要证据/异常分别标partial/failed，可重试；不以首字、历史摘要先完成、稍后补衔接、或新页码充数。超时完整结果可明确查看但仍记本次超时。
6. 完成后正文固定，显示“正文依据截止”“生成于/触发后多久”、缺口和来源。卡片当前指针持续复用ProgressState，单独显示“指针依据截止”和新鲜度；新指针不代表正文也已跟新。再次触发才刷新正文，旧结果可明确回看并保其版本。
7. 用户读懂后可跳转当前页/推导或对应定义；默认不强制翻页。需要深入查看的内容链接笔记与原依据，不自动复制进笔记或补造二次转写。

进度仍约每10秒仅根据最新可得转写与带页课件文字决策，禁止旧20秒预测、按时间加页或每分钟定位。录音中依据音频截止落后超过30秒显示“进度待更新”，保上次位置入口；不能用响应返回时间刷新证据。手动校准、快捷键、页角标记支持跳页/回页；可选跟随，用户手翻暂退。暂停/停止保最后证据，不根据墙钟继续“讲课”。正文旧、指针新和指针旧、正文生成时间新都可能发生，必须分别解释。

采集覆盖、识别覆盖、语义讲授证据分开。无录音/未匹配/课件已匹配不能推出老师未讲或整页已讲。缺录时focaus可用课件补必要背景，标资料来源及采集缺口；无法还原老师实际路径就声明，而非写成课堂事实。原始/二次转写不补造讲话，本堂资料范围不能扩为整本教材漏听清单。

## 7. 资料、原生对象与删除

导入先保存托管副本，外部原件移动/删除不影响；应用删除不删除外部原件。教材默认轻处理，课件默认深处理，用户可改用途/选范围。原页先可看，后台按页显示文字/区域/对象/未完成；局部失败可重试。

页视图与原生对象视图可对照。表格能改单元格、数据图能改数据/坐标/系列、结构图能改节点连线，原图内可恢复图表也要尝试重构。估读值标近似，未知值不填精确数字；“有截图”不显示“已完成原生重构”。局部纠正独立保存，重解析后保留或呈现冲突。

加入笔记按对象/组复制为带源可编辑副本，支持分栏、对象组合、组内局部自由布局、拖排/复制/删除/缩放/撤销。组内修改不重排其他章节。源/解析/用户纠正/笔记副本四个生命周期独立，源变化只是可更新提案。

移除课堂资料只退出未来输入，历史引用仍可追。下一次整理去掉纯失依据AI内容、保混合块有效部分和用户内容；用户文字保留并标无效来源。永久删除先显示直接引用、受影响笔记、手动副本与独立修改数量；默认保手动副本，明确说明保留内容。可预览同时删除副本，独立用户改动继续保护。确认时impact_revision不符则重看预览，不照旧计数执行。

## 8. 问答、安排、导出与恢复

本堂选段提问/概念解释/直接输入均自动检索本堂有效材料，回答分课堂证据、材料补充、AI背景；跨课程综合和主动联网不做。用户明确选择部分回答才加入笔记，带来源且仍受逐级引用约束。

作业、DDL、考试信息集中呈现原话及时间证据。教师更正显示最新明确值并保前后证据；相对日期依据实际授课日期，不确定就保原句未定。可选应用内课表支持45分钟可改、多时段、每N周、生效范围和单次/系列例外；提醒可选，用户启录，下课不自动停止。

导出三类：完整课堂包保原生内容/来源/资源/允许历史；PDF供阅读；Markdown简化。恢复先预览清单/版本/冲突与删除墓碑，再校验全部关系。无权访问的跨课堂来源保明确未解析状态，不能隐藏断链。恢复不带凭据，不自动开麦或重放已取消的模型任务。

## 9. 前端可独立检查与真实联调边界

前端用契约样例可验证六格、满格提示、浮层/IME、五档待同步、差异预览、protected range与光标保持；不能据此宣布后台录音、恢复、任务继续、云时效或永久删除通过。

真实联调必须覆盖：两个课程窗控制同一采集、拆出中断/重开、关最后一窗录音继续、退出保存、转移中迟到结果、删除中的在途生成、真实事件重放和跨窗同范围编辑。验收编号与责任见 [VALIDATION](VALIDATION.md)。


## 10. 交互知识可视化的笔记流程

### 10.1 自动插入、更新与编辑

笔记新知识段提交后后台识别值得可视化的部分，UI只显示轻量任务状态，不阻打字/录音/focaus。A识别→绑定课堂定义/参数→结构候选→N数学校验→插入提案。无需每组件询问才能自动创建，但只有来源/数学/语义合格且不相交用户/IME保护区才自动插入；被保护时保待采纳提案。无适合知识点为正常no-op，失败提示可重试，不反复添加空白占位块。

组件占普通原生块/组内对象位置，可拖排、缩放、复制、删、撤销，不能另开强制外网页或只塞截图。重整/来源更新保持object_id并给局部diff，不替换整个编辑器；已改参数/标题/对象位置按UserPatch保护。重复发现同一知识目的不重复插入，用户删除后不因新档位或重整自动补回，撤销恢复原ID和状态。复制成为独立可编辑副本，来源仍可追，原件删除影响按既有预览与副本政策处理。

参数面板区分课堂给定值、推导值、演示示例。用户探索改值后明确“演示参数”，保一键恢复课堂/默认参数与修改撤销；演示不会改写课堂Fact或老师原话。非法stride/shape/空核等就地说明并保最近合法场景，不能显示NaN/编出图形。参数草稿可即时交互，最终数值结果必须来自带参数hash的确定性校验；旧响应不覆盖新滑动值。

### 10.2 卷积与2D样例交互

2D首例可为带课堂来源公式的函数曲线/参数关系，滑动参数同时更新曲线、数据点和公式说明；示例输入显式标记。卷积3D首例是“二维卷积的三维空间展示”：输入矩阵、核、当前窗口和输出格通过同一坐标/标签联动，提供kernel size、stride、padding控制及当前shape。真实三维卷积另标D/H/W，禁止混称。conv/cross-correlation跟课堂定义，未知时标演示定义。

单步/上一部/播放暂停、输出格选择、局部逐项乘加/求和视图、旋转/缩放/重置都有键盘等价动作。视角改变不改数值，重置视角不重置用户参数。改变尺寸时明确选中格迁移/回到首格原因，不默丢输入数据。数据表和文字计算说明承担屏幕阅读器通道；颜色不是唯一对应标识，减少动效时默认暂停且允许单步。

### 10.3 视图移交、恢复和降级

拆出/放回沿用view.move/ready事务，交接已提交参数、必要视角/选中格/步骤；IME未完成或参数无法提交时保原承载并解释，不能半状态移交。新窗ready后旧窗停止渲染，两个承载不同时播放。关闭/最小化/离屏暂停并释放可重建GPU资源，后台生成任务继续；应用重启恢复参数/步骤/视角为暂停，不自动播放。

模板缺失/协议不支持/context lost/资源限额/渲染失败，组件位置保说明、数据表、可用静态预览与重试入口，笔记其他部分和录音继续。失败卡片明确交互未可用，不计生成/3D验收成功。完整课堂包恢复交互结构和资源；PDF/Markdown按当前验证状态导静态图/数据表、公式/参数/示例标签/来源及“交互已静态化”，不承诺导出后仍能旋转或恢复编辑。

## 11. 当前内容窗口全文搜索

### 11.1 Command+F与焦点

工程默认：只搜当前聚焦内容view的全文，不扩全课程/跨课程。F维护每个原生窗active_view_id，N只路由当前key window的菜单/快捷键，不广播给所有窗。拆出窗的view就是作用对象；焦点在工具栏时使用该窗最后聚焦且仍可见的内容view，无有效目标则提示先选内容。标题明确“本课件/本笔记·实际档位/本原始转写/本二次转写”，不能因左栏切课堂改变已有搜索范围。

Command+F调用自有search.open并抑制WKWebView默认find，不打开浏览器DOM查找。编辑器已提交内容经N索引；未提交IME组合不强行结束或丢弃，按键在composition结束后安全处理，必要时提示草稿尚未纳入。输入框自身的输入法Enter/Escape优先完成/取消组合，不触发跳结果/关闭。普通正文选区不在开搜索时被修改。

| 动作/状态 | 行为 |
| --- | --- |
| 打开 | 保原阅读/编辑返回锚点，聚焦搜索输入，恢复本view上次query/options；未验证旧结果先不显示snippet |
| 输入/大小写选项变化 | 增query_seq，后台查全scope；旧请求不能替换新结果。空query清空计数/高亮，无需全篇空匹配 |
| 结果 | 显示当前项/总数与覆盖状态，当前/其他命中有可区分样式；默认按文档阅读序，首次输入不抢离开输入框 |
| Enter / Shift+Enter、上下处按钮 | 下一处/上一处；末尾可环回并明确提示。已选中项仍有效时实时新增不改变当前项或滚动 |
| Escape（非composition） | 关闭搜索、清临时高亮、恢复搜索前焦点；保持用户当前阅读位置，不撤销正文编辑；query可供再次打开 |
| 无结果 | 完整覆盖时“0处”；OCR/索引未完则“已索引部分0处＋未处理范围”，不能声称全篇没有 |
| 清空 | 清query/结果/选中/高亮，输入焦点保留；不清正文或索引 |
| 关闭/拆出/重启 | 保存query/options/scope/选中锚点与搜索前返回位置；恢复需重新校验版本/删除屏障，不持久信任旧snippet |

### 11.2 内容覆盖与定位

课件搜索包括文本层/OCR/重构文字，不限已挂载页；同源原页与对象一次计数，可在原页区域和对象视图间切定位。点击命中先由N校验，再按page/region/object挂载/滚动；未OCR/失败页给范围提示，不能等全份深转换完成才搜已有文字。

笔记搜当前实际显示档，包含标题、正文、表格cell、图表/结构图标签、可视化说明与公式文本表示。显示档尚未切换时保持原scope，成功切换才刷新，不混隐藏五档。普通文字精确高亮；表格定位cell，Canvas/3D定位对象/标签及可访问说明栏，公式定位整体并展示命中规范文本，不承诺每个图形字形都有DOM范围。

原始与二次分别搜；长转写/实时追加只更新可得计数提示，原选中句ID/时间与滚动稳定。结果标原始句/二次段及原始时间，点击只导航文本。录音采集中回听入口禁用，不能借search.locate绕过PLAYBACK_BLOCKED；暂停后用户再明确播放。

### 11.3 版本变化与删除

查询固定scope snapshot/index_generation，正文更新提示“结果更新中”；当前版本变化导致旧命中无效时撤下相关高亮/计数，校验仍有效选择后再更新，不误高亮同offset的另一句话。用户可显式搜索历史快照并看到版本标签，不能自动回退历史替当前命中。

资料移出当前课堂/录音转移立即刷新当前集合范围，已有实体来源视图显示新归属；允许的历史另显式打开。永久删除立即清命中/片段/高亮，索引后台清理期间也由宿主门禁拒返回；离线窗口重连先同步删除屏障再显缓存。保留手动副本只可在其自身笔记范围搜索，来源链接显示已删除，不从旧索引取原文。

F可用契约样例验证焦点/状态/键盘/高亮；全文覆盖、精确Unicode映射、真多窗移交、删除竞态/恢复必须与N/E真实联调（V22–V24）。组件数学/资源与focaus衔接亦不能以UI样例代替V18–V21/V25/V26。
