- 新布局替代D129/D130固定三栏、D134固定底部字幕；原始/二次转写可切，字幕成为普通内容窗口。

- 显示区窗口圆角、拖动强制吸附，左上角悬停放大/缩小/关闭；放大占满显示区。
- 最多3列，各列最多上下2窗；可调列宽和列内高度。非空时自动填满显示区，消除空缺；全无窗口时为空。

- 笔记/二次转写的内容UI底部显示“上次总结于[时间]”，不混入正文；整理完成时刻与证据截止时刻语义分开。
- 顶部常驻录音/暂停继续/停止/快速跟上、浏览不改录音归属、引用保阅读位置等既有行为继续；具体多窗承载随下面决策收敛。
- D145：底栏打开所选课堂功能，每内容窗绑定并显示课堂；切换选择不重绑已有窗口，允许同课程跨课堂对照。
- D146/D151/D156：全应用单条主动麦克风采集，其他课堂开始入口提示结束当前录音或主动转移归属；转移纠正整次录音的已录/后续归属、采集不断，真正跨堂结束并新开；普通浏览不转移。两层转写随录音/引用身份保持，课件与已有笔记保归属，受影响派生内容标可更新并保护用户内容。
- D147：关闭/缩小仅改变显示，后台任务继续；拆出/放回同份视图状态，草稿/光标/滚动保持、不重复任务；放大可恢复原网格，外窗关闭后可从底栏重开。
- D148/D152：禁止格内标签组，不超过6格；满格提示先关/移出一窗，提供直接独立桌面窗打开，放回也需先腾位，不自动关闭/隐藏/替换已有内容。
- D153：约10秒讲解定位中，证据落后超过30秒标待更新，最后位置可手动查看，新有效结果恢复；不用返回时刻伪装最新。
