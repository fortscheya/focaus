# 资料转换引擎与原生文档

## 已确认范围
- D102–D112：PDF/PPTX→项目结构化格式的本地引擎为亮点；不要求完全离线。仅设计，不执行产品开发/远程调用/样本外传。
- 教材用途默认轻量提取/必要OCR，日常课件深处理，用户可调整并选页。保留原页与可操作重构视图，内容/图文关系准确优先于字体间距完全复刻。
- 原生对象：文字/公式/图片、真实单元格表格、常见数据图、简单节点连线结构图；图片中的图表也需识别并尝试原生重构。不可靠保留对照/标未完成/可重试。
- 对象保留来源文件版本/页码/区域；一键加入笔记为带源可编辑副本。笔记独立块/分栏/组合内自由布局；基础可用先完成，深处理后台进行。
- D113–D117：估读值标近似、不造缺值，纠正独立记录/重解析沿用；删源/历史/缓存默认保留手动副本并明确数量、可选预览同删，独立用户内容保护。编辑细到实际修改/输入区稳定；转场/逐步播放不实现。
- D126：内嵌音视频与外链网页仅保留资源/链接存在信息及位置，不处理其内容。
- D120–D122：首版开发验证，API由用户后供；强依赖云端，离线只保录音，离线PDF解析等不规划。托管副本与完整课堂包/PDF/Markdown仍保留，本地引擎不等于离线解析承诺。

## 官方事实核对（2026-10-17）
- PDF：可见表格可能是定位文字，扫描页可能是整页图；提取不等于恢复语义结构。https://pypdf.readthedocs.io/en/latest/user/extract-text.html 。主agent已直接读取；PyMuPDF也区分图片与矢量绘图接口，https://pymupdf.readthedocs.io/en/latest/page.html 。
- PPTX：PresentationML有形状/图片/表格等独立元素，页面可关联图表/图解/嵌入包，亦可含动画/音视频/转场。https://learn.microsoft.com/en-us/office/open-xml/presentation/structure-of-a-presentationml-document ，主agent已直接读取。
- Gemini仅限定官方事实检索，已收取复核关闭；其externalData文档的进一步主agent访问失败，不将工作簿数据细节当本轮已验证依据。
- 未处理用户PDF/PPTX、未测原生重构质量/速度/保真，不将格式规范支持等同任意输入可无损转换。
